# The repo is for reading and borrowing, not for installing

For now there is no install support. `npx skills add` installs only folders that contain a `SKILL.md`, so it cannot install the shared core, and several skills need tools most readers lack (`herdr`, Devin, Cursor). Making every skill install and run alone would mean a large rewrite and would break the chain between skills. Each skill's README lists what it needs instead.
