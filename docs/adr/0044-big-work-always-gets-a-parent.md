# Big work always gets a parent issue

Work cut into tickets always gets a parent issue, an epic, even for two tickets. An XXL issue becomes the parent. A ticket that turns out XXL inside an epic stays in it as the first piece, the new pieces join the same epic, and file-epic updates the phases and order. No epic sits inside another.

We considered two or three tickets linked by blocked-by with no parent. Every skill that reads big work would need a second shape, and the issue the work started from would have no home.
