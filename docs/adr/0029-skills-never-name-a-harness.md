# Skills never name a harness

A skill writes each step once, in words that fit every harness, such as "start the explorer" or "wait on a long command". The harness table in the shared core says how Claude Code, Codex, and Antigravity each do that step. Before this, about 15 skills said "in Claude Code do X, in Codex do Y", and Antigravity matched neither branch. We considered adding an Antigravity line to each branch, but a fourth harness would then mean editing every skill again.
