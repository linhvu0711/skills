# Skills point at files by paths relative to their own folder

A skill names its own files as `scripts/x.sh`, another skill's files as `../<skill>/...`, and the shared core as `../../shared/...`. The repo check can verify every such path, and no home folder appears in the text. The paths assume the repo's layout: skills side by side in one folder, with `shared/` next to that folder. Some agents report a skill's folder as a link path (for example `~/.claude/skills/<name>`), and `../../shared` joined to a link folder points to nothing. So each skill's first line says its paths start at its real folder, after links are followed, as `realpath` prints it.
